# INFO 662/762 Biomedical NLP Project Rubric

Fall 2026. This summary follows the course handout
`BiomedicalNLP_Project_Falll_2026(1).docx`.

## Project requirements

- Build the project on GitHub. The source code must be downloadable, buildable,
  and runnable on Cheaha from the command line or a Jupyter notebook.
- Use a clear project structure and portable paths. Avoid broken paths and
  references to directories accessible only to the developer. Give notebook
  cells descriptive titles if using a notebook.
- Write a user-facing README with instructions for setting up the environment,
  obtaining the data, and running the project.
- Each team member must have a meaningful GitHub commit history that includes
  code commits. Each member must document their individual contributions.
- Project difficulty should match the degree level and team size. The work
  should go beyond running an existing tutorial.
- If the project overlaps work for another course, disclose the overlap at
  project approval, obtain approval from both instructors, and keep the
  components distinct.

## Deliverables

- GitHub repository with source code that runs on Cheaha.
- Poster submitted electronically as a PowerPoint or PDF and printed for
  Poster Day. The printed version may use multiple sheets.
- The poster must describe the problem, methods tried, results obtained so
  far, the GitHub link, and each team member’s contributions.
- Present the poster in person unless officially exempted. The handout
  describes remote and recorded presentation arrangements for eligible
  INFO 662 students. All team members should be able to discuss the results.

## Grading

| Component | Master's | PhD |
| --- | ---: | ---: |
| Code runs on Cheaha | 10% | Required |
| Code documentation and organization | 10% | 10% |
| README | 10% | 10% |
| Methods, progress, and results | 30% | 40% |
| Poster Day delivery of information | 40% | 40% |

For PhD students, failure to execute the code can result in severe penalties,
including a zero for methods and results. The handout also states that grading
occurs in two phases and describes the talk and presentation phase as 50%.
The component table above follows the percentages listed in the handout.
